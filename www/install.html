Your money, in double entry. Private to each phone.

iPhone / iPad

Add to Home Screen

  1. Open this page in Safari (not Chrome or the Instagram/WhatsApp browser).
  2. Tap the Share button (square with an arrow).
  3. Scroll and tap Add to Home Screen, then Add.
  4. Open FinTrack from the new FT icon. It runs full screen and works offline.

Android

Install the app

  1. Tap Download for Android below.
  2. Open the downloaded fintrack.apk. If asked, allow your browser to install unknown apps.
  3. Tap Install. Updates install the same way, and your data stays.
Download for Android

The Android app also saves automatic Excel backups to Documents/FinTrack/Backups. Prefer not to install an APK? Open FinTrack in Chrome and choose Add to Home screen.

Good to know

Each person's data stays on their own phone and is never uploaded. Keep Excel backups (Manage → Data). If you delete the app, its data is deleted with it.
